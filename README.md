# Language AI MVP

AI-powered language learning app focused on conversational practice with memory between sessions.

## MVP goals

- Voice conversation with AI
- Corrections and feedback
- Memory between sessions
- User level and progress tracking
- Learned vocabulary
- Frequent mistakes
- Session summaries
- Automatic continuation from the previous session
- Multiple simple teacher avatars

## Free plan

- 10 minutes per day during the first 7 days
- 5 minutes per day after the first 7 days
- Basic memory between sessions
- Progress tracking
- Corrections and conversational practice

## Project purpose

This project is being developed incrementally as a practical software and data science portfolio project.

The goal is to apply concepts learned during the course directly to a real product, including Python, APIs, JSON, databases, backend development, deployment, testing, and data analysis.
